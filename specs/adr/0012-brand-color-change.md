# ADR-0012 品牌基色改为 #CE1B6C

- 状态：Accepted
- 决策日期：2026-11-19
- 记录日期：2026-11-19
- 决策者：项目所有者
- 取代：[ADR-0010](./0010-brand-color.md)

## 背景

ADR-0010 将品牌基色定为 `#C52935`（红色）。同日项目所有者决定改用 `#CE1B6C`（洋红），因此需要重新锚定品牌色阶。

品牌基色仍是 `raw.color.brand.500` 的唯一锚点，语义层与组件层的路径不变。

## 备选方案

**A. 保留 #C52935**：维持 ADR-0010，不重新生成色阶。

**B. 改为 #CE1B6C**：重新生成 11 级色阶，其余规则不变。

**C. 暂不决定**：S1 继续阻塞在颜色输入上。

## 决策

采用 **B**。品牌基色为 `#CE1B6C`，对应：

```text
oklch(0.5592 0.2131 1.33)
```

色阶保持色相 1.33°，只调整 L 与 C。锚点仍为 `raw.color.brand.500`。

11 级取值：

| 级 | oklch | hex（仅预览） |
| --- | --- | --- |
| 50 | `0.9750 0.0130 1.33` | #FFF3F6 |
| 100 | `0.9400 0.0322 1.33` | #FFE3EA |
| 200 | `0.8850 0.0648 1.33` | #FFC8D6 |
| 300 | `0.8000 0.1229 1.33` | #FF9BB8 |
| 400 | `0.6800 0.1900 1.33` | #F15B91 |
| **500** | **`0.5592 0.2131 1.33`** | **#CE1B6C** |
| 600 | `0.5000 0.2019 1.33` | #B5015C |
| 700 | `0.4350 0.1750 1.33` | #96014B |
| 800 | `0.3600 0.1400 1.33` | #720638 |
| 900 | `0.2900 0.1050 1.33` | #510928 |
| 950 | `0.2250 0.0750 1.33` | #350719 |

50 与 300 的彩度受 sRGB 色域限制，已按该亮度下的最大可用值收窄。

## 理由

1. **白色文字可用**：500 与白色对比 5.25:1，满足 WCAG AA 正文，可直接作主操作背景。
2. **深色文字不可用**：500 与黑色对比 4.00:1，不满足正文 AA，品牌色背景上禁止使用深色正文。
3. **与 danger 区分度提高**：brand 色相 1.33°，danger 27°，比 ADR-0010 时更容易区分。
4. **色相稳定**：固定 1.33° 可避免中间级偏红或偏紫。

## 后果

- `raw.color.brand.500` 锚定 `oklch(0.5592 0.2131 1.33)`，`raw.color.brand.50–950` 使用上表。
- ADR-0010 的红色色阶作废；依赖 `#C52935` 的草稿、截图与临时样例需重新生成。
- 主操作背景配白色文字可用；深色正文只能用于 400 及更浅级别（黑字对比 6.63 起）。
- 语义映射与暗色模式映射仍按计划在 P2 确定，不在本 ADR 预设。
- 状态色（success / warning / danger / info）不随本决策变化。

## 重新评估的触发条件

1. 品牌视觉再次调整。
2. 生成完整色阶后出现明显偏紫或超 sRGB 色域。
3. 暗色模式下无法在现有色阶内找到满足对比度的主操作色。
