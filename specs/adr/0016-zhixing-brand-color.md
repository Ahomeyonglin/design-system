# ADR-0016 第二个品牌 zhixing 与暗色阶

- 状态：Accepted
- 决策日期：2026-11-23
- 记录日期：2026-11-23
- 决策者：项目所有者
- 关联：[ADR-0012](./0012-brand-color-change.md)、[ADR-0017](./0017-brand-theme-overrides.md)

## 背景

`base` 品牌（#CE1B6C）之外需要一个色相不同的第二品牌，用于验证多品牌矩阵与品牌切换。项目所有者指定品牌名 `zhixing`、基色 `#183E7B`，并要求同时支持 light 与 dark。

基色在暗色主题下存在可用性问题：`#183E7B` 对白色文字对比 10.43:1，但对暗底 `neutral.950` 只有 1.87:1，暗色下不能再把它当作主操作背景。

## 备选方案

**A. 只做亮色**：zhixing 只声明 light，暗色禁用。

**B. 统一调整主题**：修改 `themes/dark.tokens.json`，把所有品牌的主操作调亮。

**C. 独立色阶 + 品牌级暗色覆盖**：新增完整色阶，暗色只对 zhixing 覆盖主操作相关语义颜色。

## 决策

采用 **C**。`zhixing` 提供 50–950 完整色阶，色相固定 259.59°，锚点 `raw.color.brand.500`：

```text
oklch(0.3734 0.1126 259.5882)  =  #183E7B
```

| 级 | oklch | hex（仅预览） |
| --- | --- | --- |
| 50 | `0.96 0.018 259.59` | #EBF2FE |
| 100 | `0.895 0.042 259.59` | #CCDEF9 |
| 200 | `0.79 0.075 259.59` | #9EBCEB |
| 300 | `0.65 0.105 259.59` | #6890CF |
| 400 | `0.5 0.128 259.59` | #3461AB |
| **500** | **`0.3734 0.1126 259.5882`** | **#183E7B** |
| 600 | `0.315 0.104 259.59` | #0C2F65 |
| 700 | `0.26 0.09 259.59` | #05214E |
| 800 | `0.21 0.073 259.59` | #031639 |
| 900 | `0.16 0.055 259.59` | #010C24 |
| 950 | `0.115 0.039 259.59` | #010413 |

暗色下 `semantic.color.action.primary` 的 `bg` 与 `border` 指向品牌 400，`bg-hover` 与 `border-hover` 指向品牌 500，通过 [ADR-0017](./0017-brand-theme-overrides.md) 的机制只对 zhixing 生效。

## 理由

1. **白字可读**：500 对白色对比 10.43:1，亮色可直接作主操作背景。
2. **暗色必须换档**：500 对暗底仅 1.87:1；400 对暗底 3.22:1、配白字 6.07:1，足以支撑主操作。
3. **hover 保持加深方向**：暗色 hover 从 400 回到 500，与亮色「hover 加深」的直觉一致，且白字仍保持高对比。
4. **色相稳定**：固定 259.59° 避免中间级偏紫或偏青；全部级别在 sRGB 内。
5. **不改全局主题**：其他品牌不应被这个决策影响。

## 后果

- token 包新增 `brands/zhixing.tokens.json` 与 `brands/zhixing.dark.tokens.json`。
- `manifest.json` 声明 zhixing 支持 light / dark，并登记 dark 覆盖文件。
- `raw.color.brand.*` 路径不变，语义层与组件层无需改动。
- 文档站自动出现 zhixing 品牌；CSS 产物由 3 份变 4 份。
- 暗色 zhixing 的主操作背景比亮色更亮（400 而非 500），这是有意的品牌级差异。

## 重新评估的触发条件

1. 品牌视觉再次调整，或基色变更。
2. 暗色下 400 的观感或对比度不被接受。
3. 需要第三个品牌，且其暗色策略与本决策冲突。
